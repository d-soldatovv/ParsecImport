## 1. Введение

### 1.1. Область применения

ParsecImport применяется в организациях, использующих СКУД Parsec NET 3, для автоматизации процесса массовой регистрации временных пользователей (студентов, стажеров, гостей). Система обеспечивает автоматический перенос данных из файловой структуры с фотографиями в базу данных СКУД.

Типичные сценарии применения:
* Массовая регистрация студентов при начале учебного семестра.
* Быстрое создание временных доступов для посетителей конференций или мероприятий.
* Синхронизация данных о пользователях на основе имеющихся фотоархивов.

### 1.2. Краткое описание возможностей

ParsecImport предоставляет следующие возможности:
* **Автоматический парсинг ФИО** — извлечение данных пользователя напрямую из имен файлов фотографий.
* **Интеграция с IntegrationService** — выполнение операций через SOAP API сервера Parsec NET 3.
* **Контроль дубликатов** — автоматическая проверка базы данных на наличие идентичных ФИО перед созданием записи.
* **Управление доступом** — автоматическое назначение идентификатора карты, привязка к группе доступа и установка срока действия.
* **Многопоточная обработка** — выполнение импорта в фоновом потоке, что обеспечивает отзывчивость интерфейса.
* **Детальное логирование** — запись каждого шага операции в текстовый лог и отображение ошибок в реальном времени.

### 1.3. Уровень подготовки пользователя

Пользователь (Администратор СКУД) должен обладать следующими знаниями и навыками:
* Базовое администрирование ОС Windows или Linux.
* Понимание принципов работы СКУД Parsec NET 3 (понятия «Персона», «Группа доступа», «Карта»).
* Навыки работы с файловой системой (создание папок, именование файлов).
* Базовое понимание формата JSON для редактирования конфигурационного файла.

### 1.4. Перечень эксплуатационной документации

При эксплуатации системы ParsecImport следует руководствоваться:
* Настоящим руководством пользователя.
* Техническим заданием на разработку системы.
* Спецификацией API IntegrationService (WSDL-документация).
* Документацией по установке среды исполнения Python 3.10+.



## 2. Назначение и условия применения

**ParsecImport** — инструмент автоматизации импорта данных в СКУД Parsec NET 3. Предназначена для сокращения временных затрат оператора и исключения ошибок ручного ввода при массовой регистрации пользователей.

**Архитектура системы** состоит из двух основных компонентов:
1. **Клиентское приложение (GUI)** — десктопное приложение на Python/PySide6, предоставляющее интерфейс управления и логику обработки данных.
2. **Серверный IntegrationService** — API-шлюз системы Parsec NET 3, осуществляющий запись данных в БД СКУД.

**Минимальные требования к среде:**

| Компонент | Требования |
| :--- | :--- |
| ОС рабочей станции | Windows 10/11 или Ubuntu 22.04+ (x86-64) |
| Среда исполнения | Python 3.10 или выше |
| Зависимости | PySide6 >= 6.6.0, Zeep >= 4.2.1 |
| Сеть | TCP-доступ до сервера Parsec (порт 10101) |
| Сервер Parsec | Наличие активного модуля IntegrationService |



## 3. Подготовка к работе

### 3.1. Состав и содержание дистрибутива

Программный комплекс поставляется в виде архива/репозитория со следующей структурой:

```
ParsecImport/
├── main.py              # Точка входа в приложение
├── importer_core.py     # Ядро управления процессом импорта
├── import_photos_group.py # Модуль логики обработки пользователей
├── gui_app.py           # Описание графического интерфейса
├── connection_config.json # Файл настроек подключения (шаблон)
└── logs/                # Директория для хранения итоговых отчетов
```

### 3.2. Порядок установки и запуска

**Шаг 1. Установка среды исполнения**
Убедитесь, что в системе установлен Python 3.10+. Проверить версию можно командой:
`python --version`

**Шаг 2. Установка необходимых библиотек**
Выполните установку зависимостей через менеджер пакетов pip:
`pip install PySide6 zeep lxml`

**Шаг 3. Настройка конфигурации**
Откройте файл `connection_config.json` любым текстовым редактором и укажите актуальные данные:
- `host_addr`: IP-адрес сервера Parsec.
- `username` / `password`: учетные данные администратора с правами интеграции.
- `url`: полный адрес WSDL-сервиса.

**Шаг 4. Запуск приложения**
Запустите программу из терминала или двойным кликом по исполняемому файлу:
`python main.py`

### 3.3. Порядок проверки работоспособности

**1. Проверка связи с сервером:**
В главном окне программы нажмите кнопку **«Проверить соединение»**. 
- При успехе: появится сообщение «ОК» и SessionID.
- При ошибке: появится диалоговое окно с описанием причины сбоя.

**2. Проверка доступа к группам:**
Нажмите кнопку **«Загрузить группы»**. Выпадающий список должен заполниться названиями групп доступа, полученными с сервера Parsec.



## 4. Описание операций

### 4.1. Конфигурирование подключения

Управление параметрами доступа осуществляется через файл `connection_config.json`. 
- Для смены сервера или учетных записей необходимо отредактировать значения в JSON-файле и перезапустить приложение.
- Приложение автоматически считывает эти данные при старте, что обеспечивает быструю авторизацию в сессии `OpenSession`.

### 4.2. Подготовка данных и выбор параметров

Перед запуском импорта администратор должен выполнить следующие действия:
1. **Выбор папки:** Нажать кнопку «Проводник» и указать путь к корневой папке с фотографиями.
2. **Выбор группы:** В выпадающем списке выбрать группу доступа, которую будут получить все импортируемые пользователи.
3. **Настройка периода:** Если доступ временный, установить флажок «Установить период» и выбрать даты начала и окончания действия карт в календаре.

### 4.3. Запуск и мониторинг процесса импорта

Для старта процесса нажмите кнопку **«Старт»**. После этого приложение переходит в режим выполнения:
- **Мониторинг:** В нижней части окна отображается лог событий. Каждая строка указывает статус обработки конкретного файла.
- **Индикация:** Прогресс-бар отображает процент выполнения задачи, а текстовые метки показывают текущее ФИО обрабатываемого студента.
- **Блокировка:** Все элементы настройки становятся недоступными до завершения процесса, чтобы избежать сбоев сессии.

### 4.4. Анализ результатов и работа с отчетами

После завершения импорта администратор анализирует результаты:
- **Вкладка «Дубликаты»:** содержит список пользователей, которые уже существовали в СКУД.
- **Вкладка «Ошибки»:** содержит список файлов, которые не были импортированы (например, из-за неверного имени файла).
- **Итоговый отчет:** в папке `logs/` создается текстовый файл с полной статистикой сессии, который можно сохранить для отчетности.



## 5. Аварийные ситуации

### 5.1. Сервер Parsec недоступен

**Симптом:** Ошибка при нажатии кнопки «Проверить соединение» или обрыв импорта на середине процесса.
**Действия:** 
1. Проверить сетевое соединение с сервером (команда `ping <ip_сервера>`).
2. Убедиться, что служба `IntegrationService` запущена на стороне сервера.
3. Перезапустить приложение.

### 5.2. Ошибки парсинга имен файлов

**Симптом:** В таблице «Ошибки» появляется множество записей с кодом `[FIO_PARSE]`.
**Действия:**
1. Проверить именование файлов. Файл должен называться `Фамилия Имя Отчество.jpg`.
2. Убедиться в отсутствии лишних символов или пустых имен.
3. Переименовать некорректные файлы и запустить импорт повторно.

### 5.3. Ошибки авторизации (JSON config)

**Симптом:** Сообщение об ошибке авторизации при попытке подключения.
**Действия:**
1. Проверить правильность логина и пароля в `connection_config.json`.
2. Убедиться, что учетная запись администратора имеет права на использование IntegrationService.

### 5.4. Конфликты дублирования записей

**Симптом:** Пользователь попадает в таблицу «Дубликаты», хотя администратор уверен, что его нет в системе.
**Действия:**
1. Проверить базу данных СКУД вручную через консоль Parsec.
2. Если запись ошибочна — удалить её из СКУД и повторить импорт.



## 6. Рекомендации по освоению

1. **Тестирование на малых группах:** Перед массовым импортом (сотни людей) рекомендуется создать тестовую папку с 2-3 фотографиями для проверки настроек группы доступа и периода.
2. **Соблюдение шаблона имен:** Для исключения ошибок парсинга рекомендуется использовать автоматизированные средства переименования файлов перед импортом.
3. **Контроль логов:** Внимательно следить за вкладкой «Лог» в начале процесса — первые 5-10 записей обычно показывают, правильно ли настроены права доступа.


## 7. Термины и сокращения

| Термин / Сокращение | Расшифровка и описание |
| :--- | :--- |
| **SКУД** | Система контроля и управления доступом |
| **Parsec NET 3** | Программный комплекс управления доступом |
| **SOAP** | Simple Object Access Protocol — протокол обмена данными |
| **WSDL** | Web Services Description Language — язык описания веб-сервисов |
| **IntegrationService** | API-шлюз сервера Parsec для внешней интеграции |
| **JSON** | JavaScript Object Notation — формат обмена данными для конфигурации |
| **PySide6** | Библиотека для создания графического интерфейса на Python |
| **Zeep** | Python-клиент для работы с SOAP-сервисами |
| **SessionID** | Уникальный идентификатор сессии связи с сервером |
| **VALID\_FROM / TO** | Даты начала и окончания действия карты доступа |
